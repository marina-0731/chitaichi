株式会社知多壱（設立準備中）のコーポレートサイト。

愛知県知多半島の蒸留プロジェクト。酒類に関する事業計画の情報を含むため、フッターに20歳未満の飲酒禁止と、免許取得前で製造・販売はしていない旨の注意書きを置いている（入口の年齢ゲートは、地域の応援層や20歳未満の関係者も見られるよう2026-10に廃止）。

## 構成

```
index.html                        全ページ（1枚もの・セクション遷移）
assets/
  logo.png                        知多壱ロゴ
  （知多半島の地図は index.html に SVG で直接埋め込み。国土数値情報の行政区域データから作成）
  key-visual.webp                 メインビジュアル（夕日とボトル。商品はイメージ）
  ogp.jpg                         SNSで共有したときの画像（メインビジュアルを1200x675に縮小）
  member-*.png                    メンバーのイラスト（白い背景を透明にしたもの。元画像は 20_chitaichi/メンバーイラスト/）
```

ビルド不要。静的HTMLのみで、外部ライブラリも使っていない。フォントは Google Fonts の BIZ UDP明朝（UDフォント）。

## ローカルで見る

```
python3 -m http.server 4321
```

`http://localhost:4321` を開く。`index.html` を直接ダブルクリックしても表示されるが、パスの解決がサーバー経由と異なることがあるのでサーバー越しの確認を推奨。

## 画像の扱いについて

もとは画像5枚分をすべて base64 で `index.html` に直接埋め込んでいた（6.5MB）。2026-08-29 に `assets/` へ切り出した。

同じロゴが4箇所で使われているため、埋め込み方式では**同じ画像を4回持っていた**。ファイル化したことで1枚を共有するようになり、ブラウザのキャッシュも効くようになった。

**今後、画像を追加するときも `assets/` に置いて参照する。** HTMLに直接埋め込まない。

## 多言語ページ

日本語の `index.html` が元で、ほかの10言語のページは `i18n/build.py` で作る。

| 言語 | URL | 訳文 |
|---|---|---|
| 英語（イギリス英語） | /en/ | i18n/en.json |
| 中国語（繁体字） | /zh-hant/ | i18n/zh-Hant.json |
| 中国語（簡体字） | /zh-hans/ | i18n/zh-Hans.json |
| 韓国語 | /ko/ | i18n/ko.json |
| ポルトガル語（ブラジル） | /pt/ | i18n/pt-BR.json |
| ベトナム語 | /vi/ | i18n/vi.json |
| フィリピノ語 | /fil/ | i18n/fil.json |
| フランス語 | /fr/ | i18n/fr.json |
| イタリア語 | /it/ | i18n/it.json |
| スペイン語（スペイン） | /es/ | i18n/es.json |

**各言語のフォルダの `index.html` は直接直さない。** 日本語を直したら、次の順で更新する。

```
python3 i18n/build.py extract   # 訳す文章を i18n/ja.json に書き出す
python3 i18n/build.py check     # 訳がない文章を一覧にする
（各言語の JSON に、変わった文章の訳を足す）
python3 i18n/build.py build     # 各言語のページを作り直す
```

訳文は「日本語の原文 → 訳文」の対応で持つ。原文が1文字でも変わると、その文は訳し直しになり、訳がないうちは build が止まる（日本語が混ざったページを出さないため）。`data-noi18n` を付けた要素（言語メニュー、メンバーの名前）は訳さない。
